Rish 使用说明

版本：v3.0.0.7（2026-09-10）
本版修复阅读加载、章节正则扫描和 EPUB 标题处理中的卡住与崩溃问题。
升级前请关闭旧版程序，再替换 Rish.exe；保留原目录的 .cache.dat 和 .webview.dat。

Rish 是一个轻量 Windows 阅读器，主要用于本地 TXT/EPUB 阅读和低干扰阅读场景。
当前版本还提供微信读书与自定义网址入口；这两项网页功能依赖 Microsoft Edge WebView2 Runtime。

一、开始使用

1. 解压发布包后运行 Rish.exe。
2. 使用 Ctrl+O、菜单 File > Open 或直接拖放文件，打开 TXT/EPUB。
3. 本地阅读不需要账号、服务端或网络连接。
4. 打开微信读书或新建网址时，如提示 WebView2 无法启动，请安装或修复 Microsoft Edge WebView2 Runtime。

二、常用操作

Ctrl+O：打开文件
F1：隐藏/显示边框
F2：切换背景透明（仅本地阅读）
Ctrl+T：置顶/取消置顶
Ctrl+F：全文搜索
Ctrl+G：按进度跳转
Ctrl+M：添加书签
Alt+H：隐藏/显示窗口
Ctrl+- / Ctrl+=：缩小/放大字体

快捷键可以在“设置 > 按键设置”中调整。笔记本设备上 F1 无效时，可先尝试 Fn+F1。

三、本地阅读与设置

- 支持 TXT 和 EPUB；TXT 出现显示异常时可检查字体设置和源文件编码。
- 默认正文字体为五号（10.5pt）；可在“设置 > 显示设置”调整正文/章节字体、字体颜色和背景颜色。
- 背景色、正文颜色和章节颜色都支持取色器：按住对应取色图标，移动到目标颜色后松开即可。
- 阅读进度、书签、显示设置和按键设置保存在 EXE 同级隐藏文件 .cache.dat 中。
- 如需重置本地状态：先关闭程序，备份 .cache.dat，再删除该文件并重启。删除会丢失本地设置、阅读进度和书签。
- 可使用置顶、无边框、透明度和隐藏窗口等能力构建低干扰阅读窗口。

四、微信读书与自定义网址

- 微信读书登录、内容和阅读进度由微信读书页面自行负责。
- Rish 重启后会从微信读书主页进入，不恢复微信读书内部书页，避免影响第三方的阅读同步。
- 自定义网址会保存名称、网址和缩放比例；不带协议的网址会优先尝试 HTTPS，失败后才尝试 HTTP。
- 在线书城中，自定义网址左键点击名称打开，右键点击可删除；微信读书等默认入口不可删除。
- 网页状态异常时：关闭程序，备份 EXE 同级 .webview.dat，删除后重新打开网页入口。
- 网页顶部提供后退、前进和刷新；无边框模式下顶部非按钮区域可拖动窗口，窗口边缘仍用于缩放。

五、支持边界

- Rish 不提供在线书源、账号体系、云同步、完整浏览器能力或自动更新检测。
- 请以 GitHub Release 的版本说明为准；第三方网页的登录、内容和兼容性由目标网站负责。
- 反馈问题时请提供：Rish 版本、Windows 版本、复现步骤、问题发生在本地阅读还是网页入口，以及可公开的错误截图。
