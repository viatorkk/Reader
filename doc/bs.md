# Rish 功能逻辑说明

## 项目定位

Rish 是基于 Reader Win32 桌面客户端裁剪出来的 PC 阅读版本。当前版本以本地文件阅读为主，同时在主窗口内提供微信读书 WebView 页面。它不再提供旧 Reader 的在线小说搜索、在线书源管理、代理配置、联网更新、`.ol` 在线书籍打开和在线章节抓取能力。

当前保留目标：

- 打开并阅读本地 TXT 文件。
- 打开并阅读本地 EPUB 文件。
- 保留阅读进度、历史书籍、书签、目录、全文查找、进度跳转、自动翻页、窗口控制和显示设置。
- 保留中文阅读体验，默认使用支持中文的字体设置。
- 支持在显示设置中调整全局窗口透明度。
- 支持本地 TXT/EPUB 阅读时启用“背景透明”显示。
- 提供内嵌微信读书页面：`https://weread.qq.com/`。
- 支持通过快捷键刷新微信读书 WebView 页面，默认快捷键为 `F5`。
- 保持 Visual Studio Win32 工程可继续开发和打包。

当前不保留目标：

- 在线书源配置、导入、导出和同步。
- 在线书籍搜索和创建。
- 在线章节分页请求、更新检测和缓存。
- 代理设置。
- 版本联网升级。
- MOBI 支持。

## 用户侧功能

### 文件打开

入口：

- 菜单：`文件 -> 打开`
- 默认快捷键：`Ctrl + O`
- 拖拽文件到窗口
- 最近打开文件菜单

支持格式：

- `.txt`
- `.epub`

不支持格式：

- `.ol`
- `.mobi`
- 普通在线 URL
- 其他未知扩展名

打开逻辑：

1. 用户选择或拖入文件。
2. 程序检查文件扩展名，只允许 TXT 和 EPUB。
3. TXT 使用 `TextBook` 解析。
4. EPUB 使用 `EpubBook` 解析。
5. 解析成功后显示正文，更新窗口标题、目录、阅读进度和最近打开列表。
6. 解析失败时显示打开失败、空文件或格式错误提示。

### 微信读书 WebView

入口：

- 菜单：`文件 -> WeRead`

页面地址：

```text
https://weread.qq.com/
```

实现逻辑：

1. 用户点击 WeRead 菜单。
2. 程序在当前主窗口切换到 WeRead 网页视图。
3. 主窗口内创建 Microsoft Edge WebView2 控件。
4. WebView2 使用独立用户数据目录：`%LOCALAPPDATA%\Rish\WebView2`。
5. 控件加载 `https://weread.qq.com/`。
6. 用户通过按键设置中的 `WeRead 刷新` 快捷键刷新网页，默认快捷键为 `F5`。
7. 网页缩放不再提供 Rish 自带菜单，使用 WebView/网页自身支持的浏览器快捷键完成。

刷新快捷键：

- 默认：`F5`
- 配置入口：`设置 -> 按键设置 -> WeRead 刷新`
- 当焦点在微信读书 WebView 内时，Rish 会拦截匹配的 WebView2 加速键并执行刷新。

边界说明：

- 微信读书页面只是内嵌网页，不接入旧在线书源逻辑。
- 登录、书架、阅读状态由微信读书网页自身处理。
- Rish 不解析微信读书网页内容，也不把网页内容写入本地阅读缓存。
- Rish 不注入脚本、不抓取章节、不绕过网页登录流程。
- 目标机器需要安装 Microsoft Edge WebView2 Runtime。

### 阅读视图

主阅读区负责正文绘制、翻页、滚动、查找和进度定位。阅读区保留以下操作：

- 上一页、下一页
- 上 N 行、下 N 行
- 上一章、下一章
- 全文查找
- 进度百分比跳转
- 自动翻页
- 编辑模式
- 字体放大、字体缩小

默认快捷键：

| 功能 | 默认按键 |
| --- | --- |
| 打开文件 | `Ctrl + O` |
| 添加书签 | `Ctrl + M` |
| 自动翻页 | `Space` |
| 全文查找 | `Ctrl + F` |
| 进度跳转 | `Ctrl + G` |
| 编辑模式 | `Ctrl + E` |
| 背景透明 | `F2` |
| 上一页 | `Left` |
| 下一页 | `Right` |
| 上 N 行 | `Up` |
| 下 N 行 | `Down` |
| 上一章 | `Ctrl + Left` |
| 下一章 | `Ctrl + Right` |
| 隐藏/显示边框 | `F1` |
| 置顶/取消置顶 | `Ctrl + T` |
| 字体放大 | `Ctrl + +` |
| 字体缩小 | `Ctrl + -` |

`Alt + H` 是全局热键，用于隐藏或显示窗口。是否启用全局快捷键由按键设置控制。

### 目录

入口：

- 菜单：`目录`
- 快捷键：上一章、下一章

TXT 目录解析：

- 默认规则：基于章节标题模式识别。
- 关键字规则：识别以指定关键字开头的行。
- 正则规则：使用用户输入的正则表达式匹配章节标题。

EPUB 目录解析：

- 优先使用 EPUB 内部目录信息。
- 目录节点用于跳转章节。

相关设置：

- 菜单：`设置 -> 高级设置`
- 字段：TXT 目录解析方式、关键字、正则表达式
- 显示设置中可控制章前分页。

### 书签

入口：

- 菜单：`书签`
- 默认快捷键：`Ctrl + M`

书签逻辑：

1. 用户在当前阅读位置添加书签。
2. 程序记录当前书籍和当前正文索引。
3. 书签保存到本地缓存。
4. 用户可通过书签菜单回到对应位置。

书签只服务于本地 TXT/EPUB 文件，不涉及在线章节。

### 最近打开

最近打开列表保存在本地缓存中。程序启动时读取缓存，并在文件菜单中生成历史书籍入口。

当前裁剪规则：

- TXT/EPUB 可以保留在最近打开列表。
- `.ol` 在线书籍会在无网络版本中被过滤，不再作为可打开入口展示。

### 显示设置

入口：

- 菜单：`设置 -> 显示设置`

可配置项：

- 正文字体
- 章节字体
- 使用相同字体
- 背景颜色
- 背景图片
- 背景图片显示模式：拉伸缩放、平铺、旋转平铺
- 字距
- 行距
- 段距
- 内部边框
- 目录字体跟随文本
- Word wrap
- 首行缩进
- 压缩空行
- 章前分页
- 窗口透明度：范围 `40%` 到 `100%`
- 背景透明由快捷键控制，默认快捷键为 `F2`。用于本地 TXT/EPUB 阅读；普通窗口下不再使用颜色键透明，避免背景色、字体色或 EPUB 页面颜色冲突，透明度按全窗口透明处理；隐藏边框等分层绘制模式下把阅读背景压到接近全透明的可命中 alpha，同时强制文字保持不透明。再次按下快捷键或调回普通窗口时恢复对应窗口模式的透明行为。

中文字体策略：

- 默认阅读字体使用 `Microsoft YaHei UI`。
- 默认字符集使用中文可显示的字符集。
- 从旧缓存迁移时，如果检测到旧版默认拉丁字体，会迁移到中文友好的默认字体。
- 用户打开字体选择框时，如果旧设置仍是 `ANSI_CHARSET`，会改为 `DEFAULT_CHARSET`，避免中文字符显示异常。

### 基本设置

入口：

- 菜单：`设置 -> 基本设置`

可配置项：

- 文本滚动速度
- 保留上页行数
- 鼠标点击翻页模式
- 自动翻页模式：翻页或滚动
- 自动翻页时间
- 自动翻页时间计算方式：固定时间或乘以字数
- 隐藏任务栏图标
- 最小化托盘
- 左右键同时按下隐藏窗口
- ESC 键隐藏窗口

### 按键设置

入口：

- 菜单：`设置 -> 按键设置`

可配置项：

- 是否启用每个快捷键。
- 修改每个快捷键绑定。
- 恢复默认按键配置。
- 是否启用全局热键。

校验逻辑：

- 按键不能为空。
- 快捷键不能重复。
- 全局热键注册失败时，需要用户重新设置。

### 标签设置

入口：

- 菜单：`设置 -> 标签设置`

标签用于按关键字高亮显示文本。每个标签包含：

- 关键字
- 字体
- 字体颜色
- 背景颜色
- 启用状态

标签只对本地阅读文本生效，不依赖在线书源。

### 窗口控制

保留能力：

- 隐藏/显示窗口
- 隐藏/显示边框
- 全屏/退出全屏
- 置顶/取消置顶
- 最小化到托盘
- 托盘菜单打开/退出

这些状态会写入缓存，以便下次启动恢复。

## 本地数据

### 缓存文件

缓存文件名：

```text
.cache.dat
```

缓存内容包括：

- 窗口位置和窗口状态
- 全屏恢复信息
- 阅读字体和颜色
- 背景颜色、背景图片和布局参数
- 快捷键配置
- 最近打开文件
- 当前书籍进度
- 书签
- 标签配置
- TXT 目录解析规则
- 自动翻页设置

开发注意：

- 当前版本保留旧 Reader 的缓存结构，便于兼容已有本地阅读数据。
- 结构体中仍可能存在在线书源字段，但无网络版本不应暴露 UI 入口，也不应编译在线请求逻辑。

## 已移除或禁用的模块

以下能力不属于当前 Rish 版本：

- `BooksourceDlg.*`
- `OnlineBook.*`
- `OnlineDlg.*`
- `MobiBook.*`
- `ENABLE_NETWORK`
- `ENABLE_MOBI`
- `libhttps`
- `libmobi`
- `openssl`
- `wolfssl`

工程文件中不应再引用这些源码或库。资源文件中如仍保留历史 ID，必须保证主菜单入口和命令处理不会暴露在线功能。

新增的微信读书 WebView 不属于旧在线书源系统。它只加载固定网页 `https://weread.qq.com/`，不恢复 `ENABLE_NETWORK`、`.ol` 或书源解析流程。

## 构建说明

推荐环境：

- Windows
- Visual Studio 2022 Build Tools 或 Visual Studio 2019+
- Windows SDK `10.0.19041.0` 或兼容版本
- 平台：`x86` 或 `x64`
- 配置：`Debug` 或 `Release`
- Microsoft Edge WebView2 Runtime

项目内依赖：

- `packages/Microsoft.Web.WebView2`
- WebView2 头文件路径：`packages/Microsoft.Web.WebView2/build/native/include`
- WebView2 静态加载库：`packages/Microsoft.Web.WebView2/build/native/x86` 或 `x64`

## 打包说明

当前交付目标是一个可直接运行的 Windows exe 包。

推荐包内容：

- `Rish/Rish.exe`
- `Rish/README.md`
- `Rish/LICENSE`

不建议放入包内：

- `Release` 中间目录
- `.obj`、`.pdb`、`.tlog`、`.lib` 等构建产物
- `packages/Microsoft.Web.WebView2` SDK 目录
- 源码目录

运行依赖：

- 目标电脑需要安装 Microsoft Edge WebView2 Runtime。
- 当前工程使用 WebView2 静态加载库链接，发行包不需要附带 `WebView2Loader.dll`。
- 微信读书登录态、缓存和网页数据由 WebView2 Runtime 写入 `%LOCALAPPDATA%\Rish\WebView2`。

包名建议：

```text
Rish-win32-x86-YYYYMMDD-weread.zip
```

命令行构建示例：

```bat
"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\Tools\VsDevCmd.bat" -arch=x86 -host_arch=x64
msbuild Rish.sln /p:Configuration=Release /p:Platform=x86 /m
```

开发约束：

- 打包前先清理旧 `Release` 输出，避免把旧 exe 混入包。
- 打包只放 `Rish.exe`、`README.md`、`LICENSE`，除非明确需要附加文档。
- 修改项目配置时同步检查 `Rish.vcxproj` 和 `Reader.vcxproj`。
- 不要重新引入在线书源、代理和联网升级入口。
- WeRead WebView 只允许作为固定网页入口维护，不要和旧书源解析代码耦合。

## 验收标准

一次修改完成后至少检查：

- 可以编译 `Release|x86`。
- 程序可以启动，启动后 2 秒内不崩溃。
- 打开 TXT 文件成功。
- 打开 EPUB 文件成功。
- 打开非 TXT/EPUB 文件会提示格式错误。
- 菜单中没有在线书源、代理、在线搜索入口。
- 菜单中可以打开 WeRead WebView 页面。
- WeRead WebView 支持通过默认 `F5` 或自定义快捷键刷新页面。
- 最近打开列表不展示 `.ol` 在线书籍。
- 默认字体能正常显示中文。
- 字体选择后中文字符仍能正常显示。
- 显示设置中可以保存并恢复窗口透明度。
- 打开 TXT/EPUB 后，启用“背景透明”时，阅读文字不随背景透明度变淡。
- 打包文件中没有旧 zip、PDB、OBJ、Release 中间产物。

## 后续开发建议

优先级较高：

1. 继续清理资源文件中的在线书源历史字符串和未使用 ID。
2. 为 TXT/EPUB 打开流程补最小化回归测试说明。
3. 将中文字体迁移逻辑保留为独立函数，避免后续缓存结构变动时丢失。
4. 如需恢复 MOBI，必须重新处理第三方库 CRT/zlib 链接冲突，不能直接把旧模块加回工程。
5. 如果后续需要额外网页控制项，优先接入按键设置，不再新增独立 WeRead 菜单项。

优先级较低：

1. 把旧 Reader 名称彻底替换为 Rish。
2. 整理 `README.md` 和本文件的职责边界。
3. 清理旧在线书源结构体字段，但这会影响缓存兼容性，需单独评估。
