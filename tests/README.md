# 阅读加载稳定性回归

使用 Visual Studio 2022 Build Tools、v143 和 Windows SDK 10.0.19041.0：

```powershell
.\tests\run-reading-regression.ps1
.\tests\run-reading-smoke.ps1
```

第一个脚本构建实际 Release x86 源码，再把同一批对象文件链接到无界面的测试程序。
产物在 `build/stability/`，不会覆盖原来的 `Release/Rish.exe` 或其缓存。
第二个脚本启动这份独立产物，检查 TXT 打开、窗口响应、正常退出及重启恢复。
若已有 Rish 在运行，会停止冒烟测试，避免向用户正在使用的实例发送打开文件消息。

覆盖范围：

- UTF-8、GBK（系统代码页为 936 时）、UTF-16 大小端和空内容。
- 损坏的 UTF-16、无效输入、空文件、文件不存在。
- 空匹配、普通匹配、非法及复杂章节正则；无末尾换行和 CRLF。
- 300 次快速加载的线程句柄回收、100 次启动前/执行中取消。
- 加载线程抛异常、重复打开的请求编号、实际窗口过程忽略过期通知。
- 长行 TXT 取消、32 MiB 文本的正则搜索在首次匹配前取消。
- EPUB 连续章节含缺失/空标题时的解析。

取消采用协作退出：读取、扫描和正则迭代会检查取消标记，取消时也会请求取消同步 I/O。
不再强制终止持有运行库资源的线程。第三方解析库内部调用仍需返回后才能完成清理；
这些测试不构成所有损坏 EPUB、网络盘故障或低内存环境的穷尽验证。

这些修复随 v3.0.0.7 发布，不修改保存策略、WebView 节能或界面。
